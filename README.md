# Discord Модератор Бот

Бот для модерации Discord сервера. Автоматически удаляет сообщения с запрещёнными словами и выдаёт мут нарушителям.

## Команды

- `!ban @пользователь [причина]` — бан пользователя
- `!kick @пользователь [причина]` — кик пользователя

## Структура

```
botmoderator/
├── main.py            # Запуск бота
├── config.py          # Настройки
├── requirements.txt   # Зависимости
└── cogs/
    ├── moderation.py  # Команды модерации
    └── filters.py     # Фильтр мата
```

## Установка

```bash
pip install -r requirements.txt
```

Создай `.env` с токеном:
```
DISCORD_TOKEN=твой_токен
```

Запуск:
```bash
python main.py
```

## Настройки (config.py)

- `MUTE_TIME` — время мута в минутах
- `FORBIDDEN_WORDS` — список запрещённых слов
